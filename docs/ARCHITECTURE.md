# Architecture

## 模块划分

- `data.py`：表格加载、输入格式判断、字段校验和缺失值过滤。
- `models/bp_regressor.py`：单隐藏层全连接网络、前向传播、小批量梯度下降与反向传播。
- `workflows.py`：训练/测试拆分、预处理、模型训练、预测和指标计算。
- `cli.py`：解析命令行参数，调度工作流并保存结构化结果。

## 分类流程

分类流程使用 `StandardScaler` 和 `LogisticRegression` 组成 scikit-learn Pipeline。标准化器仅在训练数据上拟合。评估阶段输出 Accuracy、Precision、Recall、F1 和混淆矩阵；二分类使用 binary 平均，多分类使用 weighted 平均。

## 回归流程

回归流程对输入特征和训练目标分别标准化。BP 网络由输入层、Sigmoid 隐藏层和线性输出层构成，使用均方误差梯度与小批量随机梯度下降更新参数。预测结果反变换到原始目标尺度后计算回归指标。

## 可复现性

分类器和 BP 网络均接收 `random_state`。默认值为 42；相同数据、参数和依赖版本下可以复现相同训练结果。

## 扩展接口

- 在 `workflows.py` 增加新的分类器或回归器。
- 在 `data.py` 增加数据库或流式数据适配器。
- 为 BP 网络增加早停、权重保存或多隐藏层配置。
- 将顺序留出替换为滚动窗口验证。

以上为扩展方向，不代表当前版本已经实现。
