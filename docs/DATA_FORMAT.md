# Data Format

## 基本结构

输入文件必须是 CSV 或 Excel 表格：

- 每一行表示一个观测样本。
- 每一列表示一个特征或目标字段。
- 参与训练的特征必须为数值列。
- 含有所选特征或目标缺失值的行会被过滤。
- 过滤后至少需要四行完整数据。

## 分类任务

`--target` 指定离散标签列。例如：

```text
temperature,vibration,pressure,fault
48.2,0.72,7.9,0
63.5,1.41,8.4,1
```

训练部分必须至少包含两个类别。

## 回归任务

`--target` 指定连续数值列。例如：

```text
temperature,vibration,pressure,remaining_time
48.2,0.72,7.9,126.4
63.5,1.41,8.4,78.1
```

## 数据顺序

工作流保留输入行顺序，并将末尾 `--test-ratio` 比例的数据作为测试集。对于按时间排列的采集记录，应先确保表格已经按时间升序排序。

## 字段选择

建议显式传入 `--features`，避免把编号、时间戳或其他数值元数据误用为模型特征。
